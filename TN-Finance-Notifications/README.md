# TN Finance Department — Notifications

Collects the notifications listed under the "Notifications" widget on the Finance Department homepage: title, file name and the link to the official PDF.

PDFs are **not** downloaded or stored in this repository; the dashboard links straight to the source site.

- Source: `https://financedept.tn.gov.in/en/`
- Manifest: `manifests/notifications.json`

## Usage

```bash
python tn_finance_notifications_sync.py
```
